# Phase 0: Project Scaffold & Global Styles — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Initialize the Angular project with the full global style foundation (colors, typography, glow effects, animations, reset) so every downstream phase can import from a consistent design system.

**Architecture:** Angular 21 standalone project with SCSS, SSR/prerendering enabled, and routing. All design tokens live as CSS custom properties on `:root`, backed by SCSS variables and mixins for compile-time use. Global SCSS partials in `src/styles/` are imported by a single `styles.scss` entry point. Google Fonts loaded via CDN for development (self-hosting deferred to Phase 9).

**Tech Stack:** Angular 21 (CLI 21.1.4), TypeScript (strict), SCSS, Angular SSR (`@angular/ssr`), Vitest

**Note:** The docs reference Angular 19 but the installed CLI is v21. Angular 21 is fully compatible with all planned patterns (standalone components, signals, OnPush, `inject()`, `isPlatformBrowser()`). The plan uses the installed CLI version.

**Note:** TDD does not apply to this phase — it's scaffolding and CSS with no business logic. Verification steps use `ng build` and `ng serve` instead of unit tests.

Flag rationale:

// ======================
// Neon Glow Mixin
// ======================

@mixin neon-glow($color, $intensity: 0.3) {
  box-shadow:
    0 0 15px rgba($color, $intensity),
    inset 0 0 15px rgba($color, $intensity * 0.2);
  border: 1px solid rgba($color, $intensity);
}

@mixin neon-glow-hover($color, $intensity: 0.5) {
  box-shadow:
    0 0 20px rgba($color, $intensity),
    0 0 40px rgba($color, $intensity * 0.3),

// Glow Presets (as mixins)
// ======================

@mixin glow-cyan($hover: false) {
